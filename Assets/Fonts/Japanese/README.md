# Noto Sans JP TMP Font Asset

`NotoSansJP-Regular SDF.asset` は Noto Sans JP (SIL Open Font License 1.1) から生成した
TextMeshPro用のStatic Font Asset（7,130文字収録）です。

出典: https://github.com/nilpkthmsk/Unity_TMP_Japanese/

`Assets/TextMesh Pro/Resources/TMP Settings.asset` の Fallback Font Assets に登録済みで、
デフォルトフォント(LiberationSans SDF)では表示できない日本語グリフをこのフォントが補います。
既存のTMP_Textコンポーネント側の設定は変更不要です。

ライセンス全文は同フォルダの `OFL.txt` を参照してください。
